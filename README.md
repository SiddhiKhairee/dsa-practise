# 100-Day FAANG+ Prep Roadmap

**For:** Sid — MS CS (NC State), targeting AI/ML + full-stack new-grad SWE roles
**Scope:** DSA (from scratch) → Pattern Mastery → Timed Drilling & Mocks → System Design → Company-Specific Tuning
**Assumption:** Starting from near-zero on formal DSA/SD prep. If a day feels easy, move faster — use freed-up time from the buffer guidance in "How to Use This Roadmap."

---

## Phase Overview

| Phase | Days | Focus |
|---|---|---|
| 1. DSA Foundations | 1-28 | Arrays, strings, hashing, linked lists, stacks/queues, recursion, trees, graphs |
| 2. Pattern Mastery | 29-56 | Two pointers, sliding window, binary search, heaps, greedy, intervals, DP, backtracking |
| 3. Timed Drilling + Mocks Begin | 57-70 | Timed mediums under pressure, first 3 mock interviews, behavioral story-building |
| 4. System Design Core + Behavioral Depth | 71-84 | SD framework, building blocks, practice designs, deep behavioral prep |
| 5. Company-Specific Tuning + Full Mocks | 85-100 | Target-company research, tagged problems, full interview-day simulations, taper |

## How to Use This Roadmap

- [ ] Do the day's checklist **in order** — each box builds on the last one
- [ ] If a day feels easy or you finish early, start tomorrow's checklist rather than over-studying today's topic
- [ ] If a day is hard and you don't finish, carry the unfinished boxes into tomorrow rather than skipping them — protect the sequence, not the calendar date
- [ ] Keep one running "weak topics" note and one "story bank" note from Day 1 onward — almost every review/mock day references them
- [ ] Review days and rest days are load-bearing, not optional — skipping them to cram new material is the most common way this kind of plan breaks down
